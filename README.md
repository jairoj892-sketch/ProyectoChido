# ProyectoChido

## Descripción
Proyecto web organizado mediante archivos HTML, CSS y JavaScript.

## Estructura del proyecto
- HTML: contiene las páginas y la estructura del sitio web.
- CSS: contiene los estilos y la presentación visual.
- JS: contiene el código JavaScript para futuras funcionalidades.
- IMAGENES: destinada a almacenar imágenes y otros recursos gráficos.

## Control de versiones
El proyecto utiliza Git para registrar los cambios mediante commits y GitHub para alojar el repositorio remoto.

## Index
Se desarrolló la página principal de la refaccionaria automovilística El Pistón, con el propósito de presentar el negocio y facilitar la navegación por las diferentes secciones del sitio web: Inicio, Productos, Servicios, Nosotros y Contacto.

En la página de inicio se incorporó una presentación del negocio con un título, una descripción general, una imagen relacionada con las refacciones automotrices y botones de acceso a los productos y al formulario de contacto. También se agregaron apartados informativos sobre aceites y lubricantes, refacciones y asesoría, así como una sección para invitar a los usuarios a solicitar información.

Además, se diseñó un pie de página con los datos generales del proyecto y se implementó una alerta de bienvenida mediante JavaScript. Para mejorar la presentación visual, se utilizó CSS para definir los colores, las tipografías, los espacios y los estilos de los botones y las tarjetas. Finalmente, se incorporó Bootstrap para organizar el contenido y facilitar la adaptación de la página a diferentes tamaños de pantalla.
