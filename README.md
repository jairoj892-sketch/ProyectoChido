# ProyectoChido

## Descripción
Proyecto web organizado mediante archivos HTML, CSS y JavaScript.

## Estructura del proyecto
- HTML: contiene las páginas y la estructura del sitio web.
- CSS: contiene los estilos y la presentación visual.
- JS: contiene el código JavaScript para futuras funcionalidades.
- IMAGENES: destinada a almacenar imágenes y otros recursos gráficos.

## Control de versiones
El proyecto utiliza Git para registrar los cambios mediante commits y GitHub para alojar el repositorio remoto.

## Index
Se desarrolló la página principal de la refaccionaria automovilística El Pistón, con el propósito de presentar el negocio y facilitar la navegación por las diferentes secciones del sitio web: Inicio, Productos, Servicios, Nosotros y Contacto.

En la página de inicio se incorporó una presentación del negocio con un título, una descripción general, una imagen relacionada con las refacciones automotrices y botones de acceso a los productos y al formulario de contacto. También se agregaron apartados informativos sobre aceites y lubricantes, refacciones y asesoría, así como una sección para invitar a los usuarios a solicitar información.

Además, se diseñó un pie de página con los datos generales del proyecto y se implementó una alerta de bienvenida mediante JavaScript. Para mejorar la presentación visual, se utilizó CSS para definir los colores, las tipografías, los espacios y los estilos de los botones y las tarjetas. Finalmente, se incorporó Bootstrap para organizar el contenido y facilitar la adaptación de la página a diferentes tamaños de pantalla.

## Apartado de productos

Se creó la página de productos de la Refaccionaria El Pistón con el propósito de mostrar algunas de las categorías de productos que ofrece el negocio. Se incluyeron las secciones de aceites y lubricantes, refacciones, baterías y accesorios, cada una con una imagen y una descripción para que los visitantes puedan identificar los productos.

También se agregó una sección de presentación con el título “Nuestros productos” y una breve descripción del catálogo. Al final de la página se incorporó un apartado que invita a los usuarios a ponerse en contacto con la refaccionaria para solicitar información sobre los productos.

Para mejorar la apariencia de la página, se creó el archivo `productos.css`, donde se definieron los tamaños de las imágenes, el diseño de las tarjetas, los colores, los espacios y los estilos de los textos y botones. Además, se incluyeron ajustes mediante una consulta de medios (*media query*) para adaptar la presentación a dispositivos móviles.

Se modificó el archivo `css.css` para mejorar el menú de navegación, agregando separación entre los enlaces, colores uniformes, efectos al pasar el cursor y una distribución vertical para pantallas pequeñas. De esta manera, se busca mantener una apariencia consistente entre las diferentes páginas del sitio.

Finalmente, se agregaron imágenes en formato PNG a la carpeta `IMAGENES` para complementar visualmente los apartados del proyecto. También se registraron los cambios mediante Git, utilizando mensajes de confirmación en español para describir las modificaciones realizadas.

## Apartado de servicios

Se creó la página de servicios de la Refaccionaria El Pistón para presentar las opciones de atención y orientación que ofrece el negocio. Se incluyeron tres secciones: asesoría sobre refacciones, información de productos y atención al cliente. Cada sección contiene un título, una descripción y una imagen relacionada con el tema.

También se agregó un enlace a la página de contacto para facilitar que los visitantes puedan solicitar información. Para mantener el diseño uniforme del sitio, se reutilizó el menú de navegación y se creó el archivo `servicios.css`, donde se establecieron los tamaños de las imágenes, el diseño de las tarjetas, los colores y los ajustes para dispositivos móviles.

## Apartado Nosotros

Se creó la página Nosotros para presentar la identidad y los objetivos de Refaccionaria El Pistón. Se incluyó información general sobre el negocio, así como los apartados de misión, visión y valores. También se agregó una imagen relacionada con la refaccionaria y un enlace a la página de contacto.

Para mantener el diseño uniforme, se reutilizó el menú de navegación y se creó el archivo `nosotros.css`. En este archivo se definieron el tamaño de la imagen, la distribución de los textos, el diseño de las tarjetas y los ajustes necesarios para adaptar la página a dispositivos móviles.
